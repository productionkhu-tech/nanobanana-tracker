About

읽는 법 · 기술 정보
비용 측정
  • 모든 비용은 USD 정가(list) 기준 — 실제 호출이 발생시킨 사용량 측정값. Free Tier 차감 전 금액입니다.
  • 원화는 1 USD ≈ 1,450원으로 환산한 추정값. 실제 GCP 청구 KRW와는 환율·세금으로 다를 수 있습니다.
데이터 지연
  • GCP 빌링 export: 1~24시간 지연. 오늘 호출은 점진적으로 합산됩니다.
  • OpenAI Admin API: 30~60분 지연. 막 호출한 건은 곧 반영됩니다.
자동화
  • GitHub Actions cron이 5분 주기로 자동 실행 (사용자 PC 무관, 24/7 동작).
  • 두 소스 수집은 한 번의 실행에서 순차 진행되며, 화면에 표시되는 시각은 통합됩니다.
  • 소스: github.com/productionkhu-tech/nanobanana-tracker
