About

읽는 법 · 기술 정보
비용 측정
  • NanoBanana 비용 = GCP 빌링 export의 invoice 합계와 동일 기준: 모든 cost_type 포함(regular + tax + adjustment), 크레딧 차감 안 함. 즉 GCP 빌링 콘솔의 "이번 달 청구액"과 1:1로 매칭됨. 부가세는 GCP가 월말 정산할 때 자동 포함됩니다.
  • GPT Image 2 비용 = OpenAI Admin API costs 엔드포인트의 USD 값 (이미 정가, 세전).
  • Seedream 비용 = BytePlus 분할청구(ListSplitBillDetail) API의 실청구액 (할인·세금 포함, USD). ModelArk 이미지 생성(Smart_Drawing_T2I) 제품만 집계. 프로젝트 귀속은 30분~1일 지연될 수 있으며 매 수집 시 당월 전체를 재조회해 자동 교정됨.
  • 원화는 GCP 빌링 export의 일별 환율(gcp_billing_export, 현재 1 USD = —원)로 환산합니다. 매 cron 실행 시 GCP가 적용한 가장 최근 환율을 다시 가져오므로 자동으로 갱신됩니다.
데이터 지연
  • GCP 빌링 export: 1~24시간 지연.
  • OpenAI Admin API: 30~60분 지연.
기간 정의
  • 오늘: 오늘 0시(UTC) 이후 누적
  • 최근 7일: 오늘 포함 7일
  • 이번 달: 이번 달 1일 ~ 오늘
  • 올해 누적 (YTD): 1월 1일 ~ 오늘. 해가 바뀌면 자동으로 0부터 다시 시작합니다 (지난해 데이터는 Reports → 월별/주별/일별 탭에 그대로 남음). 이는 빌링 / 회계의 표준 "Year to Date" 의미와 동일.
자동화 / Live
  • 수집은 GitHub Actions schedule cron이 담당 (PC 무관, 24/7).
  • 현실: workflow는 */5 * * * *로 명세돼 있지만, GitHub 무료 public repo에서 schedule은 best-effort라 부하 시 30~60분, 가끔 그 이상 지연됩니다 (공식 문서 명시). 데이터 소스 자체도 GCP 1~24h, OpenAI 30~60분 지연이 있어 결과적으로 실용 cadence는 시간 단위입니다.
  • 상태 핀이 30분 초과 시 노란색, 90분 초과 시 빨간색으로 자동 경고.
  • 대시보드는 30초마다 자동 새로고침 — 새 데이터 도착 시 펄스 애니메이션.
  • 두 소스의 수집 시각은 한 실행에서 통합되어 동일하게 표시됨.
진짜 5분 cadence가 필요할 때 (선택)
  • 워크플로는 repository_dispatch (event_type: external-cron) 트리거도 받습니다. cron-job.org 같은 무료 외부 cron 서비스에서 5분마다 GitHub POST /repos/.../dispatches를 호출하면 schedule 지연을 우회할 수 있음.
  • 이 경우 PAT를 외부 서비스에 노출하는 트레이드오프가 발생 — 대부분의 사용자는 GitHub schedule(시간 단위)로 충분합니다.
